# 食材一覧（確認用）

> `src/data/foods.json`・`src/data/stepwise.json` の内容を表にしたものです。
> 追加・削除・時期の変更などがあれば教えてください。

- **順番**: その時期の中で「次に試す食材」の候補に出る順番（小さいほど先）
- **アレルギー**: ⚠️ 特定原材料（8品目）／△ 特定原材料に準ずるもの（20品目）
- **段階**: 卵・乳製品・小麦は少しずつ量を増やす食材として、通常の候補とは別枠で進めます
